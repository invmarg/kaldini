# Kaldini — Landing "Hecho para estar aquí"

Página estática (HTML + CSS + JavaScript, sin dependencias) de la marca Kaldini, de Grupo Oxford de Venezuela.

## Contenido

- `index.html`: la página completa, con estilos y scripts incluidos.
- `assets/`: logos, banners, fotos de productos e íconos de categorías.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo `kaldini-landing`).
2. Sube `index.html`, `README.md` y la carpeta `assets/` a la raíz del repositorio.
3. En el repositorio entra a **Settings → Pages**.
4. En **Source** elige **Deploy from a branch**, la rama `main` y la carpeta `/ (root)`, y guarda.
5. En uno o dos minutos la página queda en `https://TU-USUARIO.github.io/kaldini-landing/`.

## Notas

- Las animaciones de scroll usan CSS scroll-driven animations: se ven completas en Chrome, Edge y Safari recientes. En navegadores sin soporte, la página se muestra estática y completa.
- Se respeta la preferencia del sistema "reducir movimiento".
- Las tipografías (Anton y Manrope) se cargan desde Google Fonts.
